# Poll Request

Poll Request is a simple web application that allows users to create, share, and vote on polls.

Users can create a poll by adding a question and 2–5 answer options. Each poll generates a shareable link or unique ID, allowing other users to open the poll and cast their vote. Poll results are displayed visually using simple progress bars or charts.

## Project Structure

```text
poll-request/
├── client/      # Frontend application
├── server/      # Backend API and database logic
└── documents/   # Supporting documentation, specs, and user guides
```

## Description

Poll Request is designed to make creating and sharing polls quick and straightforward. A user can create a poll, share it with others, and view the results as votes are submitted.
